# xCam - Virtual Camera Module

**xCam** is a powerful Xposed module designed to replace your device's physical camera feed with a virtual one (e.g., from a video file).

## Features
- Virtual Camera Hooking (Camera 1 and Camera 2 APIs)
- Customizable video source
- Lightweight and efficient

## Installation
1. Install the xCam APK.
2. Enable the module in your Xposed/LSPosed manager.
3. Select the target applications.
4. Configure settings in the xCam app.
5. Restart the target app.
